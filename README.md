# Grammar Challenge · English 8

Eine vollständig statische Lernwebsite zum Simple Present mit sieben aufbauenden Levels und einer 70-Prozent-Hürde.

## Auf GitHub Pages veröffentlichen

1. Ein neues öffentliches GitHub-Repository anlegen.
2. `index.html`, `style.css` und `script.js` in das Hauptverzeichnis des Repositorys hochladen.
3. Unter **Settings → Pages** bei **Build and deployment** die Option **Deploy from a branch** wählen.
4. Als Branch **main** und als Ordner **/(root)** auswählen und speichern.
5. Nach kurzer Wartezeit erscheint oben auf derselben Seite der öffentliche Link.

Die Website benötigt keinen Server und keine zusätzlichen Grafikdateien. Der Lernfortschritt wird über `localStorage` im jeweiligen Browser gespeichert.
